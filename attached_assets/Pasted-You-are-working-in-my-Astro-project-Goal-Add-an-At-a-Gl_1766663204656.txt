Add an “At-a-Glance” Pattern Summary block to the Hat Builder Wizard output so knitters can see key totals (especially total rows) without reading the whole pattern.

Files:
- astro-site/src/pages/wizards/hat-builder.astro
- (Only if needed for label text) astro-site/src/content/wizards/hat-builder.json

Placement:
- Place the summary block near the sizing SVG (directly below it or directly above it).

Content requirements (must include):
1) Total Rows (single number) for the whole hat (from Cast On through last crown row), based on the wizard’s existing row counts:
   totalRows = brimRows + bodyRowsAfterBrim + crownRows

   Use a small table or stacked rows/cards—whichever matches the site style best.

Minimum rows to include:
- Brim: rows, and stitch count during brim (usually castOnStitches)
- Body: rows (the “work ___ rows in pattern after the brim”), and stitch count during body
- Crown: rows (the crown shaping row count the wizard already outputs), and stitch count at crown start
- Optional but nice: “Crown option” label (No decreases / 4 wedges / 6 wedges)

Stitch counts (use existing wizard values; do not invent):
- Cast On stitches (totalStitches)
- Crown start stitches (should usually equal totalStitches unless your wizard changes stitch count before crown)
- If the wizard computes/knows an “ending stitches after repeats” number, you may show it, but it’s optional. Do not derive new math that conflicts with existing wording.

Wording / UI:
- Title: “At-a-Glance” or “Pattern Summary” (choose one, consistent with KBM tone)
- Show Total Rows prominently (largest item)
- Keep the rest calm and scannable

At-a-Glance
