PART 1 — ADD TOTAL STITCH COUNTS TO ROW-BY-ROW BREAKDOWN
---------------------------------------------------------

In the logic that builds the row-by-row breakdown array, update the shape event for each row so that you compute:

**totalStitchesAfter**

Rules:

• Let `currentStitches` = starting stitch count.  
  This value must be tracked and updated step-by-step.

• For EACH shaping event:
  - If shapingMode === "both":
      currentStitches = currentStitches - (sts * 2)
  - If shapingMode === "one":
      currentStitches = currentStitches - (sts * 1)

• After updating currentStitches, store that value in the row object:
  
  ```js
  row.totalStitches = currentStitches
This ensures stitch totals represent the actual stitches IN WORK after that row's shaping action, which is the expected knitting standard.

Example correctness check:

Starting: 100 sts

Both sides, decrease 1 st each side on Row 2 → new total = 98

One side, decrease 1 st on Row 2 → new total = 99
