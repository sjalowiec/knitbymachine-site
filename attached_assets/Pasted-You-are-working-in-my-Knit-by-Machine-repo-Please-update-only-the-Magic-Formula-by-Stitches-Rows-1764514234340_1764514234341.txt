2. Core logic change — auto “slope” mode

In the calculation function for Magic Formula by Stitches & Rows:

endSts (ending stitch count)

totalRows (rows available for shaping — whatever variable is currently used for rows in the MF formula)

const diffSts = Math.abs(endSts - startSts);

Add a branch:

let steps;
let warnings: string[] = [];
let mode: "standard" | "slope" = "standard";

if (diffSts > rowsAvailable) {
  // --- SLOPE MODE: shoulder-style shaping on every other row ---
  mode = "slope";

  // Number of rows where shaping can actually occur
  const shapingRows = Math.max(1, Math.floor(rowsAvailable / 2));

  // Use the existing Magic Formula spacing logic, but feed it shapingRows
  // This should return an array like [{ sts, rows, times }, ...]
  const mfSteps = runMagicFormula(diffSts, shapingRows);

  // Convert spacing back to real rows (every other row)
  steps = mfSteps.map(step => ({
    ...step,
    rows: step.rows * 2,
  }));

  warnings.push(
    "This is a steep change over a short distance. I’ve converted it to shoulder-style slope shaping: work the shaping on every other row and use short rows in between."
  );
} else {
  // --- STANDARD MODE: existing Magic Formula behavior ---
  mode = "standard";

  steps = runMagicFormula(diffSts, rowsAvailable);
}
