Components to create (Astro components + barrel export)

  - title
  - explanation text
  - action items (list)
  - optional primary action (button/link)
- Props suggestion:
  - `eyebrow?`, `title`, `explanation?`, `items?` (string[]), `actionLabel?`, `actionHref?`

4) `WizardNav.astro`

  - `onReset?` / `resetHref?`
  - Optional: `stepIndex`, `stepCount` for a simple indicator if already present
