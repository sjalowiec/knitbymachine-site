6. Triangle logic and math (UPSIDE DOWN VERSION)

We are knitting from the wide bottom edge (cast-on) up to the point.

Work entirely in inches for this first version.

Define the following variables from user input:

const bottomWidthInches; // desired bottom width (cast-on edge)
const depthInches;       // desired depth from bottom edge to point
const stitchGauge;       // stitches per inch
const rowGauge;          // rows per inch
const needlesAvailable;  // maximum needles user says they can use


Define constants inside the script:

const SAFETY_MARGIN_NEEDLES = 10;  // reserve a few needles for edges & comfort
const SEAM_ALLOWANCE_STS = 4;     // seam stitches for two-piece options
const END_STS = 3;                // small stitch count at the top point


Calculate:

const widthSts = Math.round(bottomWidthInches * stitchGauge); // cast-on stitches at bottom
const effectiveMax = needlesAvailable - SAFETY_MARGIN_NEEDLES;
const fitsInOnePiece = widthSts <= effectiveMax;

const halfWidthSts = Math.ceil(widthSts / 2) + SEAM_ALLOWANCE_STS; // per piece for 2-piece options
const halfFits = halfWidthSts <= effectiveMax;

const depthRows = Math.round(depthInches * rowGauge);


Validation:

If any value is invalid/NaN, or effectiveMax < 20, show a friendly error message in the results and stop.

Isosceles triangle (single piece) – shaping math, bottom-up

Treat this as knitting from the wide bottom edge up to the point, decreasing at both edges.

Cast on widthSts stitches at the bottom edge.

You want to reach END_STS stitches at the top point.

Each decrease row removes 2 stitches (one at each edge).

Use:

const decsNeededIso = Math.max(widthSts - END_STS, 0) / 2;


Guard against edge cases: if decsNeededIso <= 0, handle gently and set rowsPerDecIsoRounded = 1.

Then:

const rowsPerDecIso = depthRows / decsNeededIso;
const rowsPerDecIsoRounded = Math.max(1, Math.round(rowsPerDecIso));


Use this in the text:

“Cast on widthSts stitches across the bottom edge.”

“Decrease 1 stitch at each edge every rowsPerDecIsoRounded rows.”

“Continue until you have about END_STS stitches remaining or you have worked about depthRows rows.”

In the explanation, mention that this creates an isosceles triangle with the bottom edge as the widest side.

Right-angle triangle (single piece) – shaping math, bottom-up

Treat this as knitting from the wide bottom edge up to the point, decreasing on one side only.

Cast on widthSts stitches at the bottom.

You want to reach END_STS stitches at the top, shaping along one edge.

Use:

const decsNeededRt = Math.max(widthSts - END_STS, 0);
const rowsPerDecRt = depthRows / decsNeededRt;
const rowsPerDecRtRounded = Math.max(1, Math.round(rowsPerDecRt));


Use this in the text:

“Cast on widthSts stitches along the bottom edge.”

“Decrease 1 stitch at the designated shaping edge only every rowsPerDecRtRounded rows.”

“Work until you have about END_STS stitches remaining and approximately depthRows rows in total.”

In the explanatory copy, mention that this creates a right-angle triangle with the non-shaped side remaining straight.

Two mirrored halves (isosceles triangle) – shaping math, bottom-up

Each half is effectively a right triangle worked from a half-width bottom edge up to the point.

Cast-on for each half: halfWidthSts stitches.

Work to the same depth: depthRows rows.

Use:

const rowsPerDecHalfIso = depthRows / decsNeededHalfIso;
const rowsPerDecHalfIsoRounded = Math.max(1, Math.round(rowsPerDecHalfIso));


Pattern text for each half:

Two right-angle triangles – shaping math, bottom-up

The shaping math can reuse the same halfWidthSts, depthRows, and rowsPerDecHalfIsoRounded, with different assembly instructions:

Each triangle is worked from a half-width bottom edge up to a point.

The seam is along the long diagonal (hypotenuse).

Pattern text:

“For each, cast on halfWidthSts stitches along the bottom edge.”

“Decrease 1 stitch at the shaping edge every rowsPerDecHalfIsoRounded rows until you have about END_STS stitches and approximately depthRows rows.”

“Join the two triangles along their long edges (the hypotenuse) to form the full triangle, with the combined bottom edges forming the full width.”
