B) Fix the disappearing submit button on hover

This is almost always caused by one of these:

opacity: 0 or color: transparent on :hover

z-index stacking with an overlay/pseudo-element

mix-blend-mode or filter side effects

background changing to match page background

4) Add a defensive CSS fix (scoped)

In your community page CSS (or global button CSS), add a safe hover/focus rule for .kbm-button:

.kbm-button {
  position: relative;
  z-index: 1;
  opacity: 1;
  visibility: visible;
}

.kbm-button:hover,
.kbm-button:focus,
.kbm-button:focus-visible {
  opacity: 1;
  visibility: visible;
  filter: none;
  mix-blend-mode: normal;
}

5) If the button is being covered by something, fix stacking context

Also ensure the form container doesn’t create a weird stacking context:

.kbm-gate-form {
  position: relative;
  z-index: 1;
}

6) Ensure hover styles don’t “erase” text

If you have hover styles that set background to transparent or text to the same color, correct them so the text stays readable:

.kbm-button:hover {
  color: inherit;          /* or a readable explicit value if you already have design tokens */
  background-color: inherit; /* keep visible; if you use variables, keep them */
}


(Use your existing theme variables if present; the key is: don’t let hover match the background.)
