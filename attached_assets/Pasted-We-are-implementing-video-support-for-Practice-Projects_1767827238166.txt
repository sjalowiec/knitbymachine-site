1) ADD VIMEO VIDEO HELPERS (SERVER SIDE)
------------------------------------------------------------

Create a new helper module:

src/lib/vimeo.ts

Export the following functions:

- extractVimeoId(url: string): string | null
  Supports:
    - https://vimeo.com/123456789
    - https://player.vimeo.com/video/123456789
    - URLs with query params
  Returns the numeric ID as a string or null.

- toVimeoPlayerUrl(url: string): string
  Converts:
    vimeo.com/{id} → https://player.vimeo.com/video/{id}
  Returns original url if conversion fails.

- async getVimeoThumbnailUrl(videoUrl: string): Promise<string | null>
  Logic:
    - Extract Vimeo ID
    - Check cache first
    - If cache miss or stale:
        Fetch oEmbed JSON from:
        https://vimeo.com/api/oembed.json?url=https://vimeo.com/{id}
    - Read `thumbnail_url`
    - Write to cache
    - Return thumbnail_url or null on failure
