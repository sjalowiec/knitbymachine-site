When printing the Hat Pattern Builder page, hide all interactive input controls
and replace them with a compact, read-only summary of the user’s selections.

- astro-site/src/pages/wizards/hat-builder.astro
- (Optional) existing CSS file for print styles

--------------------------------
PRINT BEHAVIOR (REQUIRED)
--------------------------------

1) On screen (default):
- Keep all inputs, selectors, and controls exactly as they are.

2) On print:
- Hide all form controls:
  - input
  - select
  - textarea
  - radio buttons
  - checkboxes
  - sliders
  - buttons
- Hide section dividers meant only for interaction.

3) On print, replace the wizard UI with a summary block that:

  - Hat size (custom or standard)
  - Brim style
  - Crown style
  - Fit style
  - Gauge (stitches and rows over 4")
- Displays these as plain text (no inputs).

IMPLEMENTATION GUIDANCE
--------------------------------

Option A (preferred, minimal logic):
- Add a hidden “print-summary” container in the wizard markup that:
  - mirrors the selected values using the same state variables
  - is hidden on screen
  - shown only in print

CSS example intent (not literal):

@media print {
  .wizard-inputs { display: none !important; }

}
