Mode logic

In [slug].astro:

Get the params and URL:

const { slug } = Astro.params;
const url = Astro.url;
const agent = await getEntryBySlug('ai-agents', slug);
if (!agent) throw new Error(`AI Agent not found for slug: ${slug}`);
const data = agent.data;


Determine which mode to show:

const fromParam = url.searchParams.get('from');
const forcedOnboarding = fromParam === 'home' || fromParam === 'onboarding';
const onboardingMode = forcedOnboarding || data.onboardingMode === true;


Derive text values:

const pageTitle = data.title;
const subheading = onboardingMode
  ? (data.onboardingIntroTitle ?? data.excerpt ?? '')
  : (data.toolSubheading ?? data.excerpt ?? '');
const metaTitle = data.metaTitle ?? pageTitle;
const metaDescription = data.metaDescription ?? data.excerpt ?? '';
const primaryCtaLabel = `Start ${pageTitle}`;
const hasVideo = Boolean(data.videoUrl);
const hasRelatedGuides = Array.isArray(data.relatedGuides) && data.relatedGuides.length > 0;
