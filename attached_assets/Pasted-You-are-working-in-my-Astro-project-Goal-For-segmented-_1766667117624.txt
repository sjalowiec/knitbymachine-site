1) CAST-ON ADJUSTMENT (SEGMENTED WEDGES ONLY)
------------------------------------------------------------

Current issue:
If cast-on stitches do not divide evenly by wedgeCount, the pattern includes special-case text like:
“For 21-stitch wedges…” / “For 20-stitch wedges…”

Fix:
When segmented wedge crown is selected, adjust the cast-on stitch count to an even multiple of wedgeCount so all wedges are identical.

Definitions:
- wedgeCount = 4 or 6
- originalCastOn = the wizard’s computed cast-on stitches before this adjustment
- adjustedCastOn = the nearest lower multiple of wedgeCount (round DOWN)
  adjustedCastOn = originalCastOn - (originalCastOn % wedgeCount)

Important:
- Only apply this adjustment for segmented wedge crowns.
- For all other crown types, keep originalCastOn unchanged.

The pattern should use adjustedCastOn everywhere it references cast-on stitches for segmented wedge crowns (including any body/crown stitch counts).

Also compute:
- wedgeStitches = adjustedCastOn / wedgeCount
