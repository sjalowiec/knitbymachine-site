2) Update the application API handler to redirect on success

Find the POST handler for the application form submission. It may be one of these:

src/pages/api/guided-workshop-application.ts

src/pages/api/guided-workshop-application.js

src/pages/api/guided-workshop-application/index.ts

Update the successful response so it redirects to the new page:

Set status to 303

Set header Location to /guided-workshop/thanks

Example (Astro endpoint style):

return new Response(null, {
  status: 303,
  headers: {
    Location: "/guided-workshop/thanks",
  },
});


If your handler currently returns JSON like { ok: true }, replace that success return with the redirect above.

3) Verify the form submits normally (no fetch)

On the application page, make sure the form uses a normal POST:

method="POST"

action="/api/guided-workshop-application"

If you are submitting via fetch() in a script, remove that and allow a normal form POST (so the server redirect works reliably).
