A content folder for workshop instances (one JSON per workshop)

A dynamic hub slug page that renders from JSON

Rules

If any file already exists, update it instead of creating a duplicate.

Keep styling consistent with the existing hub page (reuse its classes/CSS).

Step 4 — Create the dynamic hub slug page

Create this route if missing:

src/pages/guided-workshops/[workshopSlug]/hub.astro

Requirements:

Use getStaticPaths() to generate hub pages for each workshop JSON.

Load workshop data via getWorkshopBySlug(params.workshopSlug).

If no workshop found, return a friendly 404-ish message inside your normal BaseLayout.

MOST IMPORTANT: The rendered HTML should be based on the existing hub page we created:

Copy the section structure and class names

Workshop title/subtitle if used

Day list
