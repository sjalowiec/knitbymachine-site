3. Add JavaScript to send starter text into the MindPal iframe

At the bottom of getting-started/index.astro, just before the closing </Layout> (but still inside it), add a <script> block that:

Finds all .kbm-chip--starter buttons

On click, reads their data-starter text

Locates the iframe inside .kbm-agent-wrapper

Sends a postMessage into the iframe with that text

Add this:

  <script>
    // Attach click handlers to starter chips once the DOM is ready
    document.addEventListener('DOMContentLoaded', () => {
      const chips = document.querySelectorAll('.kbm-chip--starter');

      chips.forEach((chip) => {
        chip.addEventListener('click', () => {
          const starterText = chip.getAttribute('data-starter');
          if (!starterText) return;

          // Find the MindPal iframe inside the agent wrapper
          const agentWrapper = document.querySelector('.kbm-agent-wrapper');
          if (!agentWrapper) return;

          const iframe = agentWrapper.querySelector('iframe');
          if (!iframe || !iframe.contentWindow) {
            console.warn('MindPal iframe not found inside .kbm-agent-wrapper');
            return;
          }

          // TODO: adjust this message format to match MindPal's embed API
          // This is a generic postMessage you can update later.
          iframe.contentWindow.postMessage(
            {
              type: 'kbm_starter_message',
              text: starterText,
              source: 'kbm-getting-started-page'
            },
            '*'
          );
        });
      });
    });
  </script>
</Layout>


If Astro complains about JSX-style comments, replace // with standard JS comments exactly as shown; don’t use {/* */} because this is plain HTML <script>, not JSX.

⚠ Important:
This postMessage payload is a placeholder.
Once you know MindPal’s exact embed API, you can:

Change type: 'kbm_starter_message' to whatever MindPal expects.

Or, if MindPal auto-focuses the input on incoming messages, plug into that.

For now, this gives you a clean, single place to adjust later.
