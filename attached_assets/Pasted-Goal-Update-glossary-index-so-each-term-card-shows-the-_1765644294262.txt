In the glossary index page where term cards are rendered, replace the flip-card markup with this structure:

<article class="term-card" data-title="{titleLower}">
  <!-- Card header: shows tooltip + toggles image panel -->
  <button class="term-head" type="button" aria-expanded="false">
    <div class="term-head-text">

    </div>
    <span class="term-chevron" aria-hidden="true">▾</span>
  </button>

  <!-- Accordion panel: IMAGE ONLY -->
  <div class="term-panel" hidden>
    {# if image exists #}
    <a class="term-image-link" href="/glossary/{slug}" aria-label="Open full entry for {title}">

        src="{image}"
        alt="{imageAlt || title}"
        loading="lazy"
        class="term-image kbm-unified-image"
      />
      <span class="term-open-link">Open full entry →</span>
    </a>

    {# if no image exists #}
    <!-- show a clean link only (no empty box) -->
    <a class="term-fallback-link" href="/glossary/{slug}">
      Open full entry →
    </a>
  </div>
</article>

Use tooltip on the index card (not description/definition).
