🧱 Step-by-Step Instructions
1️⃣ Load video data from the Videos content collection (Astro side)

At the top of index.astro:

Import getCollection from astro:content

Load only the videos used on this page (by slug)

For each video, retrieve:

title

embedUrl (or equivalent Vimeo embed src)

transcriptHtml

Create a small lookup object keyed by slug so it can be used in markup.

2️⃣ Video cards → modal triggers

For each video card on the page:

Keep the existing card layout

Ensure the clickable element is a <button>

Add data attributes populated by Astro:

data-video-slug

data-embed-src

data-title

These replace the hard-coded JS Vimeo map used on the reference page.

3️⃣ Transcript toggle buttons (same UX as reference)

Under each video card:

Add a button with:

class: jotb-transcript-trigger

data-transcript-toggle="<slug>"

icon: <i class="fa-regular fa-file-lines"></i>

label span: .jotb-trigger-label

Default label: Show transcript

4️⃣ Transcript accordions

For each video:

Add a <details> block:

id="transcript-<slug>"

class: jotb-transcript-accordion

Inside:

hidden <summary> (same as reference)

transcript container rendering transcriptHtml

Do not hardcode transcript text

5️⃣ Modal markup (reuse structure verbatim)

At the bottom of the page, include the modal markup identical to the reference:

.video-modal

.video-modal__backdrop with data-close

.video-modal__dialog

header with title + close button

.video-frame container for iframe injection

IDs and structure must match so the JS ports cleanly.

6️⃣ Client-side JS (ported, not reinvented)

Inline <script> at the bottom of the page:

Transcript logic

Copy the transcript toggle logic exactly from the reference page

Keep:

aria-expanded syncing

MutationObserver watching <details>

label swap Show ↔ Hide

Update selectors only if class names differ

Modal logic

Copy modal open/close logic exactly

Remove the hard-coded m = {} Vimeo map

Instead:

Read data-embed-src and data-title from the clicked button

Keep:

ESC to close

backdrop click

focus return to triggering card

body.modal-open scroll lock
