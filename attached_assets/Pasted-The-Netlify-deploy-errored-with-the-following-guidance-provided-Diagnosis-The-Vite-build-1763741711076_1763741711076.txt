The Netlify deploy errored, with the following guidance provided:

**Diagnosis**

The Vite build fails when it tries to load `astro-site/src/pages/ana/[slug].astro` because the component contains `<script src="/scripts/dynamic-tooltips.js">`. Astro requires any `<script>` tag that points to a file in the `public/` directory to include the `is:inline` directive, otherwise the asset won’t be bundled and build stops ([lines 95-97](#L95-L97)).

**Solution**

Edit `astro-site/src/pages/ana/[slug].astro` and update the script tag so the file from `public/scripts/dynamic-tooltips.js` is marked inline, for example:

```astro
<script is:inline src="/scripts/dynamic-tooltips.js"></script>
```

Alternatively, move the script into `src/` and import it as a module
