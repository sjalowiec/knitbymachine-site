------------------------------------------------------------
SPIRAL CROWN — STRUCTURE & LOGIC
------------------------------------------------------------

Spiral decreases are worked in TWO PHASES.

Phase 1 establishes the spiral visually.
Phase 2 accelerates shaping to close the crown smoothly.

The decrease positions shift naturally because the spacing between decreases is reduced each time.

------------------------------------------------------------
SPIRAL CROWN — PATTERN OUTPUT
------------------------------------------------------------

Output the following instructions when “Spiral Crown” is selected:

------------------------------------------------------------

Crown Shaping
Spiral Crown (Smooth, Continuous)

Decrease 1 stitch (definition):
Transfer the next stitch to its neighboring needle, then shift stitches to fill the empty needle.

Spiral decreases are worked in two phases. Each decrease round reduces the number of stitches between decreases, creating a smooth spiral effect.

PHASE 1 — Establish the Spiral

Decrease Row:
Count 8 stitches. Decrease 1 stitch.
Repeat evenly across the row.
Knit the row.

Work 2 rows even.

Next Decrease Row:
Count 7 stitches. Decrease 1 stitch.
Repeat evenly across the row.
Knit the row.

Continue working decrease rows every 3rd row, each time counting 1 fewer stitch between decreases
(6, 5, 4, etc.), until approximately 12 stitches remain.

PHASE 2 — Close the Crown

Work decrease rows every row, continuing to reduce the spacing between decreases,
until 4–6 stitches remain.

Finish:
Cut yarn, thread through remaining stitches, pull tight, and secure.
