Update my ANA index page by adding:

A trigger link (“Didn’t find your question? Ask Sue →”) directly below the hero text.

A fully functioning modal that opens when the link is clicked.

The ActiveCampaign inline form embed inside the modal.

The required JavaScript and CSS.

ana-catalog.astro


✅ 1. Add the trigger link under the hero

Find the hero section where ANA introduces the page.
Immediately after the hero paragraph (description text), insert this:

<!-- Ask Sue Trigger Link -->
<p class="ask-link-wrapper" style="margin-top: 0.5rem;">
  <a href="#" id="openAskModal" class="ask-link" style="color: var(--kbm-green); font-weight: 600;">
    Didn’t find your question? Ask Sue →
  </a>
</p>

✅ 2. Add the modal HTML at the bottom of the page (before the end)

Insert this block near the bottom of the Astro file, before any closing layout tags, but still inside the <body> content:

<!-- Ask Sue Modal -->
<div id="askModal" class="ask-modal" hidden>
  <div class="ask-modal__overlay"></div>

  <div class="ask-modal__content">
    <button type="button" class="ask-modal__close" id="closeAskModal" aria-label="Close">
      &times;
    </button>

    <h2 class="ask-modal__title">Ask Sue a Question</h2>
    <p class="ask-modal__intro">
      I read every question and may add it to Ask ’n Answer so other machine knitters can benefit too.
    </p>

    <div class="ask-modal__form">
      <!-- ActiveCampaign Inline Form Embed -->
      <div class="_form_5"></div>
      <script src="https://knitbymachine.activehosted.com/f/embed.php?id=5" charset="utf-8"></script>
    </div>
  </div>
</div>

✅ 3. Add the open/close modal JavaScript

Add this script directly after the modal HTML:

<script>
  if (typeof window !== "undefined") {
    const openBtn = document.getElementById("openAskModal");
    const modal = document.getElementById("askModal");
    const closeBtn = document.getElementById("closeAskModal");
    const overlay = modal?.querySelector(".ask-modal__overlay");

    openBtn?.addEventListener("click", (e) => {
      e.preventDefault();
      modal?.removeAttribute("hidden");
      document.body.style.overflow = "hidden";
    });

    closeBtn?.addEventListener("click", () => {
      modal?.setAttribute("hidden", "true");
      document.body.style.overflow = "";
    });

    overlay?.addEventListener("click", () => {
      modal?.setAttribute("hidden", "true");
      document.body.style.overflow = "";
    });
  }
</script>
