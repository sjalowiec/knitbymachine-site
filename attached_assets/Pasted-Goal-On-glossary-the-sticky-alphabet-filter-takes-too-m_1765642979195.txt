Goal: On /glossary, the sticky alphabet filter takes too much space on mobile. Keep the alphabet on desktop, but on screens <= 768px replace it with a compact “Jump to letter” button that opens a small overlay of letters.

Steps

Keep existing alphabet markup for desktop
Do not delete your current .alphabet-filter / .alphabet block.

Add a new mobile-only control above the grid
Insert this just above the glossary results grid:

<div class="alpha-mobile">
  <button type="button" class="alpha-mobile-btn" aria-expanded="false" aria-controls="alphaMobilePanel">
    Jump to a letter
    <span class="alpha-mobile-caret">▾</span>
  </button>

  <div id="alphaMobilePanel" class="alpha-mobile-panel" hidden>
    <!-- Clone the same A–Z links you already render (only active letters enabled) -->
    <div class="alpha-mobile-letters">
      <!-- A, B, C... -->
    </div>
  </div>
</div>


CSS: desktop keeps sticky, mobile hides it

On mobile, hide the sticky alphabet bar and show the button:

/* Default: show desktop alphabet, hide mobile control */
.alpha-mobile { display: none; }

@media (max-width: 768px) {
  .alphabet-filter { display: none; }
  .alpha-mobile { display: block; margin: 0 auto 1rem; padding: 0 1.5rem; max-width: 1200px; }

  .alpha-mobile-btn {
    width: 100%;
    display: flex;
    justify-content: space-between;
    align-items: center;
    padding: .75rem 1rem;
    border-radius: 999px;
    border: 1px solid rgba(82, 104, 45, 0.22);
    background: #fff;
    color: var(--kbm-green, #52682d);
    font-weight: 800;
    cursor: pointer;
  }

  .alpha-mobile-panel {
    margin-top: .75rem;
    border-radius: 16px;
    border: 1px solid rgba(82, 104, 45, 0.18);
    background: #fff;
    padding: .75rem;
    box-shadow: 0 12px 30px rgba(0,0,0,0.08);
  }

  .alpha-mobile-letters {
    display: grid;
    grid-template-columns: repeat(6, minmax(0, 1fr));
    gap: .35rem;
  }

  .alpha-mobile-letters a {
    text-align: center;
    padding: .5rem 0;
    border-radius: 10px;
    font-weight: 800;
    color: var(--kbm-green, #52682d);

    border: 1px solid rgba(82, 104, 45, 0.14);
  }

  .alpha-mobile-letters a.disabled {
    opacity: .35;
    pointer-events: none;
  }
}


JS: toggle the mobile panel + close on selection

Add JS that:

toggles hidden on #alphaMobilePanel

updates aria-expanded

closes the panel after a letter is tapped

closes if user taps outside

Hook letters into your existing filter logic

If your alphabet filter is currently JS-based (not real anchors), call the same filter function when a mobile letter is clicked.

If it’s anchor-based, just use the same href="#A" etc and close the panel after click.

Expected result

Mobile: no sticky alphabet taking space. One clean “Jump to a letter” button.

Desktop: keep your current alphabet behavior.

Page feels calmer and more modern; content gets the room.
