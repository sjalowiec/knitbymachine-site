CALCULATION LOGIC
Implement the Magic Formula logic in a small helper function (either in the same file or a shared utility):

Inputs to the helper:
- startingSts (number)
- endingSts (number)
- totalRows (number)
- stsGauge (number)  // sts per inch or cm
- rowsGauge (number) // rows per inch or cm
- units ("in" | "cm")
- shapingMode ("one-side" | "both-sides")

Derived values:
- totalChange = Math.abs(startingSts - endingSts)
- direction = startingSts > endingSts ? "decrease" : "increase"

For shapingMode === "both-sides":
- changesPerSide = totalChange / 2
- If not an integer, floor it for one side, ceil for the other, and return information for both sides.

For shapingMode === "one-side":
- changesPerSide = totalChange  (all shaping is on one side)

Spacing calculation (per side):
- baseInterval = Math.floor(totalRows / changesPerSide)
- extraRows = totalRows % changesPerSide

Return a structure that lets the UI display:
- A summary like: 
  - “Decrease 1 stitch every [baseInterval] rows [changesPerSide - extraRows] times, then every [baseInterval + 1] rows [extraRows] times.”
- And optionally a per-row breakdown as an array of steps:
  - Each element includes:
    - rowNumber
    - action ("decrease 1 stitch" or "increase 1 stitch")
    - which side ("each side", "right side only", etc. based on shapingMode)

Approximate shaping length:
- lengthInUnits = totalRows / rowsGauge
- If units === "cm", compute using metric gauge or convert from inches as appropriate.
- Return this so the UI can show:
  - “This shaping spans about X.X inches/cm.”
