Wizard UI Requirements
A) Gauge Inputs

stitches (number, required, > 0)

rows (number, required, > 0)

Unit toggle:

in = stitches per inch / rows per inch

cm = stitches per centimeter / rows per centimeter

B) Paper Options

Paper size:

Bold line frequency:

C) Actions

SVG Output Requirements (Critical)
True-Scale Rules

SVG must use real-world units.

Letter:

width="8.5in" height="11in"

A4:

Use mm or convert to inches internally — either is acceptable.

Printing at 100% must preserve scale.

Cell Dimensions

Unit = in:

cell width = 1 / stitches inches

cell height = 1 / rows inches

Unit = cm:

cell width = 1 / stitches cm

cell height = 1 / rows cm

If converting to inches internally: divide by 2.54

Grid Features

Light grid for every cell

Bold grid lines every N cells (5 or 10)

Reference guides:

in → every 1 inch
(stitches cells horizontally, rows cells vertically)

cm → every 5 cm
(stitches * 5 and rows * 5 cells)

Margins + Footer Band (Required)

Page margin: 0.25in (or 6mm) on all sides

Footer band height: 0.25in (or 6mm)

The grid must stop above the footer band.

Do not allow grid lines into the footer area.
